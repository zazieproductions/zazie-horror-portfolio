# Feature: portfolio (homepage + production records)

- `/` is committed static HTML (meaningful before JS) enhanced by the legacy
  React bundle. Its `<head>` and poster cards are regenerated by
  `scripts/prerender.mjs` from `src/data/` — edit data, not the HTML head.
- 9 production records live in `src/data/productions.ts` → flat pages under
  `work/<slug>.html`. Credits are role-specific and source-linked; the archive
  never implies a composing credit it cannot source (e.g. UNSEEN's composer is
  Steve Merlo — the page says so).
- Poster pipeline: `images/posters/<slug>-{640.avif,640.jpg,1200.jpg}` with
  explicit `width`/`height`; 1200px variant loads only in the lightbox.
